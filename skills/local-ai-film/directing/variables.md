# 正交变量表

**开片必填。五维全填完才准写分镜。**

填完立刻走 `fingerprint.md` 查重，撞维要重选。

---

## 为什么要有这张表

因为「记得每次不一样」这句话被证明无效。旧版 SKILL.md 第 10 行白纸黑字写着「风格和时长不预设，每次现想」，结果四部预告片（山海 + SCP×3）逐镜同构，四部氛围片全是 17 镜。

**约束必须可填、可判、有拦截动作。** 这张表提供可填的选项，`fingerprint.md` 提供可判的规则。

---

## 五个维度

维度之间尽量正交 —— 改一维不牵动其他维。

### 时间结构

事件在片中被排列的顺序。

| 取值 | 说明 | 状态 |
|---|---|---|
| `线性` | 按事件发生顺序推进 | ✅ 已验证（全部 8 部历史片） |
| `倒叙` | 先给结果，再回溯成因 | ⬜ 未自测 |
| `循环` | 结尾回到开头，形成闭环 | ⬜ 未自测 |
| `平行切` | 两条线交替推进，互不相遇 | ⬜ 未自测 |
| `单时刻切片` | 全片是同一瞬间的多个侧面，无时间推进 | ⬜ 未自测 |

⚠️ `循环` 要求首尾镜高度相似，对一致性是额外压力。`平行切` 需要两套 LOOK，出图量翻倍。

### 视点

镜头代表谁在看。

| 取值 | 说明 | 状态 |
|---|---|---|
| `全知` | 上帝视角，可去任何地方 | ✅ 已验证（山海、SCP×3） |
| `跟随单人` | 始终贴着一个人物 | ✅ 已验证（夜班、唯美治愈v2） |
| `监控·仪器` | 通过监控画面、仪表、取景器观看 | 🟡 部分（SCP 用过几镜，未整片贯彻） |
| `物的视角` | 镜头是某个物件的位置 | ⬜ 未自测 |
| `缺席` | 主体从不出现，只拍其痕迹 | ⚠️ 高风险 —— 见 `../knowledge/prompt-craft.md` 三-C，模型会把缺席的东西补出来，需额外重抽预算 |

### 节奏型

镜头时长在全片的分布形状。

| 取值 | 说明 | 状态 |
|---|---|---|
| `匀速` | 每镜等长 | ✅ 已验证（4 部氛围片） |
| `加速爆发` | 逐段加快，末段最密 | ✅ 已验证（山海、SCP×3） |
| `前紧后松` | 开头密集，逐渐拉开 | ⬜ 未自测 |
| `两次呼吸` | 密-疏-密-疏，两个波峰 | ⬜ 未自测 |
| `全片凝滞` | 全部取 `max_shot_sec` 上限，一刀不快切 | ⬜ 未自测 |

⚠️ `全片凝滞` 在 `max_shot_sec` 小的 profile 上做不出来 —— 本机 2.04 秒的上限意味着「凝滞」也是 30 次/分的切换密度，达不到凝滞的观感。**需 `max_shot_sec ≥ 5`。**

### 声音

音轨的组织方式。做法见 `../knowledge/bgm-spectral.md` 第四节。

| 取值 | 说明 | 状态 |
|---|---|---|
| `BGM通铺` | 一首曲子铺满全片 | ✅ 已验证（全部 8 部） |
| `音效驱动` | BGM 只作底，逐镜音效撑起节奏 | 🟡 预告片设计里写了，未严格执行 |
| `环境声` | 无 BGM，全靠现场声 | ⬜ 未自测 |
| `完全静音` | 极少数镜有声，其余纯静 | ⬜ 未自测 |
| `声画错位` | 声音属于相邻镜，制造不安 | ⬜ 未自测 |

⚠️ `环境声` / `完全静音` 需要额外音源 —— 本地生成的素材是无声的，这两项要另配音效库。

### 结尾

最后 1–3 镜的收束方式。

| 取值 | 说明 | 状态 |
|---|---|---|
| `空景收` | 拉到大远景空镜结束 | 🔴 **已用 7/8 部，强烈建议避开** |
| `回到首镜` | 末镜与首镜同机位同景别 | ⬜ 未自测 |
| `硬切黑` | 高潮中途直接切黑，不给收束 | ⬜ 未自测 |
| `悬而未决` | 停在一个动作中间，不给结果 | ⬜ 未自测 |
| `日常化` | 从异常回落到极普通的日常场景 | 🟡 SCP 用过（办公楼、公路），但仍套在大远景里 |

---

## ⚠️ 「做不到」往往是 profile 的问题，不是取值的问题

上面标 ⚠️ 的几条限制全部来自 `ltx-2.3-q4-12g` 这一个档。换 profile 就变：

| 取值 | `ltx-2.3-q4-12g`（2.04 s） | `minimax-h3-cloud`（15 s） |
|---|---|---|
| `tempo: 全片凝滞` | ✗ 上限 2.04 秒，最慢也是 30 次/分 | ✅ |
| `time: 循环` | 🟡 靠首末镜相似度硬凑 | ✅ 首尾帧 I2V 可真闭环 |
| `audio: 环境声` | ✗ 素材无声，须另配音效库 | ✅ 原生音频随视频出 |

**碰到「这个取值做不出来」时，先问一句是取值的问题还是 profile 的问题。**
换档能解决的，不要改创作意图去迁就工具。

反过来也成立：`minimax-h3-cloud` 的 15 秒上限会让 `directing/structures/` 现有三套骨架全部失效
（镜数公式会算出 1–2 镜）。**换 profile 要连骨架一起换。**

## 状态标记的含义

| 标记 | 含义 |
|---|---|
| ✅ 已验证 | 至少一部成片完整用过，效果可接受 |
| 🟡 部分 | 用过但未整片贯彻，或效果未确认 |
| ⬜ 未自测 | **选项是设计出来的，没跑过。可能做不出来。** |
| 🔴 | 用得过多，应主动避开 |
| ⚠️ | 有前置条件或额外成本 |

**未自测的取值不是「不能选」，而是「选了要留返工预算」。** 首次使用某个未自测取值时，建议先跑一部 20 秒短片验证，别直接上长片。

用完请回来更新状态 —— 这张表的价值随使用次数增长。

## 填写模板

```yaml
time:   线性 | 倒叙 | 循环 | 平行切 | 单时刻切片
pov:    全知 | 跟随单人 | 监控·仪器 | 物的视角 | 缺席
tempo:  匀速 | 加速爆发 | 前紧后松 | 两次呼吸 | 全片凝滞
audio:  BGM通铺 | 音效驱动 | 环境声 | 完全静音 | 声画错位
ending: 空景收 | 回到首镜 | 硬切黑 | 悬而未决 | 日常化
```

填完 → `fingerprint.md`。
