# 预告片八段式

⚠️ **已用 4 次，全部预告片都是这一套。** 再用第 5 次前，先确认 `fingerprint.md` 的 `structure` 层放行条件（须给出显式理由），并且 `signature` 层不撞。

这是**候选之一**，不是预告片的唯一写法。写新骨架用 `_TEMPLATE.md`。

---

## 与氛围片是两套语法

现有氛围片的每条设计原则几乎都要反过来：

| | 氛围片 | 预告片 |
|---|---|---|
| 单镜时长 | 统一 `max_shot_sec` | **0.35–3.0s 剧烈变化** |
| 节奏 | 匀速 | 加速 → 急停 → 爆发 |
| 运镜 | locked-off | **逐镜推轨**，快切段急推 |
| 转场 | xfade 溶解 | **硬切** |
| 声音 | BGM 通铺 | **音效驱动**，BGM 只是底 |
| 画幅 | 16:9 / 9:16 | **2.39:1** |

## 关键洞察：`max_shot_sec` 是上限不是定长

快切段每镜只要 0.35–0.7 秒，用的是素材里最稳的前 15 帧，漂移风险为零。反过来说，**快切段的运动提示词可以写得激进得多**。

长镜反向受限：超过可用帧数只能慢放补足，不能靠 trim。可用秒数 = `(frame_count - trim) / fps`，慢放倍率 > 1.6 开始顿挫，控制在 1.5 以内。

## 段落骨架（36–41 镜，53–62 秒）

```
冷开场 3镜 × 2.5s   → 建立 6–7镜 × 2.2s → 推进 8–9镜 × 1.4s
→ 加速 8–9镜 × 0.6s → 【急停 2镜 × 1.5s】→ 爆发 6–7镜 × 0.4s
→ 标题卡 3.0s       → 收尾 3–4镜 × 2.7s
```

三条实测结论：

- **急停那 1.5 秒是全片最重要的设计** —— 没有它，爆发段只是吵
- **收尾要给足 10 秒以上**，只给 5 秒会被判「戛然而止」
- **人物镜压到 15% 以下** —— 预告片不该早早交代主角，世界本身要占主导（33% 被判「人物镜太多」）

## 用 `examples/scripts/trailer_edit.py`

通用拼接做不了这个（见 `../../knowledge/pitfalls.md` 坑 ⑤）。配置里加：

```python
"edit": {"s01": (2.6, 0, "in"), ...},   # (成片时长, trim起点, 运镜)
"title": {"text": "山  海", "dur": 3.0, "after": "s37"},
"canvas": (1920, 804),
"curves": "0/0 0.25/0.21 0.75/0.84 1/1",
```

运镜类型：`in` 缓推 / `IN` 急推 / `out` 缓拉 / `OUT` 急拉 / `up` 上摇 / `side` 侧移 / `shake` 手持 / `still` 静止。

## 调色别压过头

预告片要压黑，但 `eq` 高对比 + 减亮度 + `curves` 三层叠加会让整片黑到看不清。

- 可用：`eq=saturation=0.86:contrast=1.16` + `curves=0/0 0.25/0.21 0.75/0.84 1/1`
- 翻车：`contrast=1.28:brightness=-0.04` + `curves 0.25/0.16`

## 已知的同质化陷阱

用这套骨架时，以下位置**四部片全部撞过**，务必换掉：

| 位置 | 四部都用了什么 | 建议 |
|---|---|---|
| 急停段（第 25 镜） | 摘掉遮脸物 + 近乎全黑 | 换成不涉及人物的急停：一个突然静止的机械、一片骤停的水面 |
| 急停后（第 26 镜） | 极特写眼睛/汗珠 | 换成非人体的极特写 |
| 爆发段 | 6 × 极特写连打 | 换成中景连打、或景别交替 |
| 末镜 | 大远景空景 | 见 `../variables.md` 结尾维，`空景收` 已 7/8 |
