# 紧循环

为「时间结构 = 循环 / 结尾 = 回到首镜 / 节奏型 = 前紧后松」这一组变量表取值写的骨架。

`trailer-8seg` 与 `ambient-flat` 都已 `use_count: 4`，这套是第三条路。

---

## 适用什么

- 没有人物弧线、靠**同一场景被反复观察**产生意义的题材
- 监控·仪器视点，或物的视角
- 短片（15–30 秒）。**长片不适用** —— 循环结构撑不过 40 秒，观众会先于回扣猜到

**不适用**：有明确事件推进的题材（循环会削弱因果）、需要人物一致性的题材（本骨架的强项恰恰是不拍人）。

## 前置要求

```yaml
requires:
  motion_style: frozen     # 前段快切依赖「静止画面 + 微动环境」，动作弧线会毁掉节奏
```

对 `max_shot_sec` 无下限要求 —— 前段本来就只取 1 秒左右，后段取满上限即可。**上限越小，前后对比越弱**，`max_shot_sec < 1.5` 时本骨架失去意义。

## 骨架

```
前段（紧）N₁ 镜 × 1.0s  →  后段（松）N₂ 镜 × max_shot_sec
```

- **硬切，不用 xfade**。溶解会把前段的密集感糊掉
- 前后段镜数比约 **4 : 3**
- 末镜必须与首镜同机位同景别，**只改一处细节**

## 镜头数公式

```
N₁ = round(总秒数 × 0.4 / 1.0)
N₂ = round(总秒数 × 0.6 / max_shot_sec)
镜头数 = N₁ + N₂
总时长 = N₁ × 1.0 + N₂ × max_shot_sec      # 硬切，无转场扣减
```

本机 profile（`max_shot_sec: 2.04`）下 20 秒档 = 8 + 6 = **14 镜**，实际 20.24 秒。

### ⚠️ 切换密度必须分段报，全片均值无意义

本骨架的密度是双极的，报均值会同时误导你和用户：

| 段 | 刀数 | 密度 |
|---|---|---|
| 前段 | 8 刀 / 8.00 s | **60 次/分** |
| 后段 | 6 刀 / 12.24 s | **29 次/分** |
| 全片均值 | 13 刀 / 20.24 s | 38.5 次/分 ← **这个数谁都不描述** |

`ambient-flat` 是匀速的，均值有意义；本骨架不是。**开跑前报「前段 60、后段 29」，不要报 38.5。**

前段 60 次/分远超常见氛围片（15 次/分），这是设计意图 —— 前段本来就是要建立一份「场景清单」，快到观众来不及细看。

## 关键设计点

**末镜的那一处改变，是全片唯一的信息。**

首镜要拍得足够具体、足够容易记住（一个有明确颜色或形状的细节），否则观众在末镜认不出来「这是同一个画面」，整个结构失效。

改变必须**只有一处**，而且是同一个物件的属性变化（颜色、位置、数量），不能换物件。改两处观众会以为是随机的另一个镜头。

第二关键点：**后段不是「慢下来收尾」，是「让观众有时间开始怀疑」**。前段快切建立场景清单，后段放慢让人重新打量。所以后段的镜头应当与前段有重叠的物件，不要引入全新元素。

### ⚠️ 中段绝不能再出现与首末镜同类的画面（首次实测踩到）

《自助洗衣店》第一版把 s10 也写成了滚筒舷窗特写。出图后：

| 镜 | 画面 | 衣物颜色 |
|---|---|---|
| s01 | 滚筒舷窗特写 | 深蓝 |
| **s10** | **滚筒舷窗特写** | **白** |
| s14 | 滚筒舷窗特写 | 浅黄 |

三个同类画面三种颜色，观众不会读成「同一台机器变了」，只会读成「三台不同的机器」。**末镜那一处改变从信息降级成噪音，整个骨架失效。**

规则：**首末镜用的那个物件，中段一次都不能再以同等景别出现。** 背景里远远带到无所谓，特写不行。

写完分镜后专门查一遍：把 14 个镜的主体列出来，看首镜的主体是否只出现了两次（第 1 和第 N）。

## 调色 / 拼接注意

- 16:9，`canvas: (1920, 1080)`，不加黑边
- 硬切用 concat demuxer，**不要用 `xfade duration=0`**（见 `../../knowledge/pitfalls.md` 坑 ⑤）
- 监控质感靠低饱和 + 轻噪点，不要靠降分辨率
- BGM 通铺，成片 RMS 目标 0.075（无对白档）

## 已知的同质化陷阱

| 位置 | 用过什么 | 建议 |
|---|---|---|
| 首末镜物件 | 洗衣机滚筒舷窗（圆形玻璃 + 内容物变色） | 换成非圆形、非容器类的物件 |
| 改变方式 | 颜色变化 | 试位置变化、数量变化 |
| 场所类型 | 24 小时无人值守商业空间 | 试自然场景、交通工具内部 |
