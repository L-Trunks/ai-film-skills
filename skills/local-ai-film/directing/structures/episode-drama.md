# 对白剧情片·分集式

给 **long-shot 族 + 原生带音频**的模型用的剧集骨架。
`trailer-8seg` / `ambient-flat` / `loop-tight` 三套的镜数公式在 5.17 秒单镜下**全部失效**，
所以这套是重算的，不是改的。

---

## 适用什么

- 有台词、有角色、有连续剧情，观众会去核对"这是不是同一个人"
- **一章原著 → 两集**，每集 1'45"–2'00"、30–40 镜
- 主角 1–2 人 + 配角 3–5 人，场景 3–4 个

**不适用**：氛围片、预告片、纯旁白片。那三类没有角色一致性和台词对齐的约束，
用这套是自找麻烦。

## 前置要求

```yaml
requires:
  family: long-shot
  native_audio: true          # 没有原生音频就没有口型，改走后期配音也行但要重排流程
  max_shot_sec: ">= 5"
  first_last_frame: true      # 首帧链要用
```

⚠️ 还有一条不在 profile 里的前置：**必须先有常量层和定妆图**
（`../../knowledge/dialogue-drama.md` 第一节）。造型没定死就开跑，跑完全废。

## 骨架

一集 = 三到四个**场**，场内用镜长档控节奏，不是每镜等长：

```
[预叙冷开场 1镜 × 3.0s]           ← 只在第 01 集有，借的是后面某集的一拍
黑场时间卡 1.2s
场A 建立   8–10镜 · 标点1.5 / 常规3.0 混排
场B 冲突   12–14镜 · 常规3.0 为主，情绪点给 4.0
场C 收束   8–10镜 · 4.0 收尾，末镜留白
```

**镜长只给三档：标点 1.5 / 常规 3.0 / 情绪 4.0。**
5.0 试过，判定太长 —— 长单镜模型给得起，但观众坐不住。

## 镜头数公式

```
镜数     = 目标秒数 / 加权平均镜长        # 加权平均 ≈ 2.8s（三档按 2:6:2 混）
生成段数 = ceil(镜数 / 每段镜数)          # 每段镜数 = floor(max_shot_sec / 加权平均镜长)
```

`minimax-h3-local` 下：`max_shot_sec = 5.17` → 每段 1–2 镜 →
110 秒的一集 ≈ 39 镜 ≈ 30 段生成。**这是真正的成本项**，一集约三小时 GPU。

⚠️ 段数一旦定了就别再"顺手加一镜" —— 每段要重启 ComfyUI，加一镜是加六分钟。

## 关键设计点

### ① 一章拆两集，不是一章一集

原著一章的信息量做成一集，必然要么塞不下要么注水。拆成两集之后：
每集有自己的一个**完整小转折**，结尾各自留一个钩子。
这也是把片长压在 2 分钟内的唯一办法 —— 超过 2 分钟，角色漂移和造型不连续的暴露面积陡增。

### ② 冷开场借的是**后面**的一拍，不是本集的

第 01 集开头那 3 秒是第 03 集的高潮画面。这一拍必须配**闪回三件套**：

```
暖调分离  +  黑场时间卡「十二小时前」  +  声音落差
```

**三层缺一不可。** 只做画面不做声音，观众读不出这是回忆，
只会觉得开头那一镜莫名其妙。

⚠️ 插了黑场卡，**剪辑 / 混音 / 字幕三处时间轴都要算上它**。

### ③ 视觉签名：找一个"不拍脸"的机位，全片复用

我们的是**贴地只拍鞋**。它的来历很实际：一个「背影走远」的镜抽三次全废
（位移做不到，见判停清单），改成贴地拍脚，比原设计更狠。

一个反复出现的非常规机位，比任何"风格化调色"都更能把一部片钉成一部片，
而且它天然规避了小脸被超分拧坏的问题。

### ④ 画内文字只留大号阿拉伯数字，并让它跨集复用

中文和小字必糊，大号数字能出。所以把关键信息设计成数字
（我们的是评级数值 `0.3` / `43.7`），然后**把同一个数字做成跨集符号**。

### ⑤ BGM 显式分段，对白交锋段不给音乐

第一版是「从某镜起铺到片尾」，实测覆盖 94% —— **一直响着等于没响**。
改成显式段落后降到 19% / 34%。判据只有一条：**对白交锋的地方一律静音**。

## 调色 / 拼接注意

出片顺序**不能颠倒**：

```
剪辑 → 超分（必须在混音前）→ 混音 → 字幕
```

字幕字号按成片分辨率标定，烧在超分前的原生尺寸上会相对偏大。

其余（抢话、字幕重叠、音效名单漏加工）见
`../../knowledge/dialogue-drama.md` 第六节，那四个都是"各算各的"型 bug。

## 已知的同质化陷阱

| 位置 | 用过什么 | 建议 |
|---|---|---|
| 冷开场 | 高潮画面预叙 + 时间卡 | 用过一次就够了；第二次观众会觉得是套路 |
| 视觉签名 | 贴地拍鞋（两集共 3 处） | 换个机位母题，别把"贴地"变成第二个 `ending_size: 大远景` |
| 每集末镜 | 主角独自留在原地 | — |
| 场景数 | 3–4 个 | — |
