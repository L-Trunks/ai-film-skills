# 带对白的剧情片

> 适用：`family: long-shot` 且模型原生带音频（如 `minimax-h3-local`）。
> 氛围片和预告片**没有**下面这些问题 —— 它们没有角色要认、没有台词要对、没有第二集。

氛围片可以每镜各美各的，观众不会去核对。剧情片不行：
**同一个人要在四十个镜头里是同一个人，穿同一件衣服，说的话要接得上，第二集还要接第一集。**
这一整条约束链是新的，下面全是为它服务的。

## ⚠️ 先说结论：12 GB 卡上，这条线做不出「能跟短剧比」的东西

四集跑完之后我们自己的判断，写在最前面免得别人重走一遍：

**做得出片子，做不出短剧。** 两个卡点都不是手艺问题：

1. **时间成本的量级不对。** 736×416、5.17 秒一段，本地 H3 每镜 6–8 分钟，
   每段还要重启一次 ComfyUI。两集 68 镜跑一整夜（7.6 小时）出 55 镜，
   剩下的靠白天补。一集正片 1 分 45 秒。按这个速率，一部短剧的体量是**以月计**的。
2. **分辨率压死了表演。** 0.31 MP 里中景人脸只有 40–90 px。
   于是「带人物的镜里近景以上要占 76%」变成硬约束 —— 不是导演选择，是被迫的。
   中远景只能给背影和定场，**而短剧恰恰要靠中景演对手戏**。
   超分是加细节不是去糊，救不了生成端就没有的信息。

⛔ **别用「画风简单一点就能省」来绕。** 我们整条线用的就是不追求细节的动画画风，
两个卡点一个没变 —— 它们来自分辨率和单镜耗时，跟画风复杂度无关。

**那这份文档还有什么用？** 下面每一条都是拿真跑批换来的，
换到云端 API 或更大显存上照样成立 —— 常量层、判停清单、姿态链、验收自动化
都是**片子本身的问题**，不是显存的问题。
12 GB 本地这条路适合：单集、短片、氛围片、预告片、演示片。
**要连续产出短剧，先解决那两个量级问题，别指望提示词。**

## 一、常量层：把角色和场景写成一份可改的"圣经"

所有角色描述、场景描述**收进一个共享模块**，分镜只引用不复制。
改这里等于改全片；分镜里散着抄一遍，第 20 镜必然和第 3 镜漂开。

配套两条纪律：

- **先跑定妆图**。角色和场景各出一张基准图，**造型没定死不许开跑关键帧**。
- ⛔ **常量层里一个 `never` 都不许写**。要排他就写正向的样子
  （`never wide-eyed` → 「她的眼睑低垂、放松」）。
  `never X` 在 cfg=1 的工作流里不是"不生效"，是**召唤 X**（`pitfalls.md` 坑 ⑫）。
- ⛔ **不要在角色常量里补画风词去"加固"**。画风由统一的 LOOK 锚承担，
  补了就是引狼入室 —— 尤其别写"这不是照片"，说了就是照片。
- **常量要按场景挑**。顺手把"走廊群演"常量加到早点铺那一镜，
  铺子里就站了一堆陌生人。

### 三个画风锚，不是一个

| 锚 | 用在 |
|---|---|
| `LOOK` | 有人的镜 |
| `LOOK_OBJ` | 纯物件镜 —— 去掉人脸布光段，换成表面材质布光 |
| `LOOK_BACK` | 背影镜 |

⚠️ `LOOK` 里那段人脸布光描述**不只坑物件镜，背影镜也会被它顶成正面**。
这一条废了三次才定位到。

## 二、判停清单：模型做不到的，换写法，不要重抽 ★

剧情片最贵的浪费是**拿重抽去撞模型的能力边界**。
下面六类抽多少次都不会对，直接改分镜：

| 做不到 | 换成 |
|---|---|
| 机械开合（舱盖掀开、抽屉拉出） | 关着的空镜 **硬切** 开着的空镜 |
| 群体连锁反应（一排人依次回头） | 单人反应 + 画外声 |
| 走位（走进来、走出画） | 直接画「已到位」 |
| 画内文字 | 只留**大号阿拉伯数字**（`0.3` `43.7` `80` 能出；中文和小字必糊） |
| 多人互动（A 给 B 戴上某物） | 拆成单人镜，用视线缝起来 |
| 手部纹理级特征 | 改成姿势级特征 |

⚠️ **「走位」这条的边界要说准：做不到的是位移，不是动作幅度大。**
起立、坐下、转身、弯腰这类**原地姿态变化**，长单镜模型演得出来。
把它们一起砍掉是过度保守。

### ⛔ 只砍画面不补声音就露馅

判停砍掉的东西**要在声音层补回来**。一排人依次回头砍成了单人镜，
那"一片骚动声"必须还在；开舱的机械声必须还在。
只砍不补，观众听得出这里缺了一块。

## 三、同机位状态变化：走图生图，不走文生图

「关着的舱 → 硬切 → 开着的舱」要成立，必须**同机位同景别**。
文生图保证不了：写 `the exact same camera position as before` 照样换个房间。

正解是拿上一镜的成品当底图走 **Qwen-Image-Edit**（保构图、改状态），一次成功。
**这类镜（开门 / 抽屉 / 屏幕明灭 / 灯亮灯灭）以后一律走它。**

### ⛔ 3.1 同一镜内部状态要变的：关键帧一律画「变化**之前**」★★

上面说的是**跨镜**硬切。**同一镜内部**要演出一个变化（涟漪扩散、裂缝亮起、按下指印），
另有一条更容易犯的错：**关键帧就是首帧，视频模型只能从它往后演。**

写关键帧提示词时，人会自然去描述最好看的那一瞬 —— 扩散开的涟漪、已经亮起的裂纹、
纸上那枚红指印 —— **而那正是终点**。画了终点，模型就只能倒着演回起点。
2026-08 实测 4 例，两种症状一个根因：

| 分镜要的 | 实际出的 | 症状 |
|---|---|---|
| 水面静止 → 一滴水落下 → 涟漪扩散 | 开头就有涟漪，然后散去归于平静 | 倒放 |
| 石头暗着 → 裂开 → 橘光升起稳住 | 开头裂纹已经亮着，然后熄灭 | 倒放 |
| 拇指按下 → 抬起 → **留下暗红指印** | 开头卷轴上已有红印，结尾**被擦干净成白卷** | 倒放 |
| 屏幕暗着 → 亮起 → 数字出现 | 从头到尾就亮着，什么都没发生 | 静止 |

⛔ **这一族专挑最关键的那一镜坏** —— 第三例是那一集的题眼（「画押」），
落在一张白卷上等于整集的戏点塌掉。

**规矩：状态会变的镜，关键帧画「之前」，变化过程交给 motion 字段描述。**
改完实测四例全部转正（暗石头 → 裂开 → 橘光涌出稳住）。

**两条配套的：**

- ⛔ **别拿 `last_frame`（首尾同图）去「钉住终点姿势给下一镜接戏」。**
  首尾同图的语义是「结束时回到起点」，用在状态变化镜上会把动作整个锁死 ——
  我们有一镜是「手放下石头、再抬手离开」，挂了首尾同图，出来是一段几乎不动的死段。
  接戏该靠下一镜的动作接切关键帧去接，不是靠上一镜锁死自己。
- ⛔ **有关键数字/文字的镜是例外，不要改首帧。**
  屏幕上那个数字一旦交给视频模型自己长，命中率就没谱了（T2I 画大号阿拉伯数字很稳，
  视频模型不稳）。宁可接受一段「一直亮着」的静止镜 —— 剪辑里它本来也只用 1.5–2 秒。
  这一族改 motion（给微动：状态条呼吸、扫描线），不改首帧。

⚠️ **死段检测器抓不到这一族**，别指望它：它量的是帧间变化**大小**，不管方向。
倒放得最彻底的那一镜分数反而是全集最高。**唯一可靠的查法是抽首末两帧并排看** ——
先从 motion 字段里挑出「无 → 有」的不可逆事件镜（亮起/出现/裂开/留下印子），
只查这几镜就够，一集通常只有 3–5 个。

## 四、复用旧素材 = 把旧素材的病一起复用进来 ★

重做一版时，为省跑批时间标了 18 个镜「复用上一版的视频」。
跑完才发现上一版里同一个角色出了 4 套衣服 —— **而造型不连续正是这一版要治的头号病**。

一般形式：

> **复用的前提是「旧素材在你要改的那个维度上合格」，不是「旧素材还能看」。**

上一版在构图、表演、画风上都合格，唯独造型不合格，
那就**一个带人物的镜都不能复用**；纯物件镜和群演镜不受影响。

## 五、台词只能有一个来源 ★

台词会同时被四个下游读：提示词（口型）、配音、字幕、剪辑表。
存四份就会漂 —— 我们上一版存了三份，其中一句已经漂了三个字，成片里字幕和配音对不上。

**唯一来源 = 分镜数据结构里的 `audio` 字段**，其余全部从它取。
配套两条：

- **口型数据按集分文件**。第二集的镜号和第一集重名、但视频已经换了，
  串了会把口型贴到错的地方。
- **提示词里不写旁白台词**，除非这一镜真的要口型 ——
  写了会被画成字幕（`pitfalls.md` 坑 ⑫）。

## 六、后期：四个「各算各的」型 bug

剧情片的后期是多条时间轴叠在一起（配音、字幕、信息条、音效、BGM）。
它们各自都算得对，**合起来就打架** —— 这一类 bug 单看每个模块都查不出来。

| Bug | 根因 | 修法 |
|---|---|---|
| **抢话** | 每镜的配音落点各镜独立算，谁也不知道上一句说完没有。一句 4.13 秒的台词配在 1.80 秒的镜上，溢出 2.33 秒盖住下一镜 | 设最小间隔，**全片时间轴顺扫一遍**，压上来的往后推、级联传导 |
| **字幕重叠** | 只对"对白"做了去重叠，信息条是后面单独追加的，时间独立算、y 坐标还跟对白一样贴底 | 信息条先找空档，找不到走顶部分层 |
| **音效漏加工** | 需要变声的名单写在 A 处，真正的加工函数里写死的是**上一版的镜号**，新镜号不在名单里 → 成片里是没加工的干声，而且不报错 | 名单和实现取同一份数据 |
| **BGM 通铺** | 「从某镜起铺到片尾」，实测覆盖 94%。**一直响着等于没响** | 显式写段落，判据是**对白交锋段一律不给音乐**。降到 19%/34% |

⚠️ **字幕的"最小时长"兜底会撤销你的去重叠**：
掐完结束时间之后又来一句 `if 时长 < 0.6: 结束 = 开始 + 0.6`，把它推了回去。
两条规则的先后顺序要想清楚。

⚠️ **总线上的 `dynaudnorm` 会把安静段抬起来。**
石头说话后面留的"尾拍"回声只能留**一拍** —— 两拍会被抬到跟正词同响，
听感变成同一个词说了三遍。

### 出片顺序

```
剪辑 → 超分（必须在混音前）→ 混音 → 字幕
```

字幕字号是按成片分辨率标定的，烧在超分前的原生尺寸上会相对偏大。

## 七、跨集

- **镜号在集之间会重名**，所有按镜号索引的中间数据（口型、音效、剪辑表）**按集分文件**。
- **跨镜同一张脸要逐条抄特征**。漏抄了年龄那一条，下一镜就出了个完全不同的人。
- **符号可以跨集复用**：我们把第一集那个「0.3」的红章原样搬到第二集，
  比新造一个符号有效得多 —— 而且它正好是画内文字里唯一能稳定生成的形态（大号数字）。
- **预叙冷开场**要配"闪回三件套"：暖调分离 + 黑场时间卡 + 声音落差，**三层缺一不可**。
  只做画面不做声音，观众读不出这是回忆。
- 插了黑场时间卡，**三处时间轴（剪辑 / 混音 / 字幕）都要算上它**。

- [ ] 定妆图先跑，造型定死了才开关键帧
- [ ] 常量层零 `never`、零画风词
- [ ] 物件镜和背影镜换了不带人脸段的画风锚
- [ ] 做不到的六类已经换写法，没有拿重抽去撞
- [ ] 判停砍掉的东西在声音层补回来了

- [ ] 台词只有一个来源，四个下游都从它取
