# 结构化分镜表提示词

**适用：`max_shot_sec ≥ 5` 且支持段内切镜的 profile（如 `minimax-h3-local`）。**
`ltx-2.3-q4-12g` 那种 2.04 秒单镜档不适用 —— 一次生成就一个镜头，没有「表」可排。

---

## 为什么需要它

短单镜（LTX 2.04s）时代，一次生成 = 一个镜头 = 一句散文式描述，够用。

长单镜 + 段内切镜（H3 5.17s，一次能出 3 个镜头）之后，散文式写法立刻暴露两个问题：

| 问题 | 实测表现 |
|---|---|
| **镜头时长失控** | 写「三个镜头硬切」，出来是 0.6s / 1.2s / 3.4s，第一镜根本看不清 |
| **关系性动作做不出来** | 写「她的头靠在镜头的肩上」，出的是她独自躺在草地上 |

两个问题都被同一套写法解决。

---

## 格式

```
【风格】…质感、光线、色调、画幅
【时长】N 秒
【场景】具体地点 + 时间 + 背景元素
【角色】完整外貌描述（每段原样重复，一字不改）
【道具】手里拿的东西

[00:00-00:02.5] 镜头1
画面：…
台词：…
音效：…

[00:02.5-00:05.2] 镜头2
画面：硬切。…
台词：…
音效：…

【导演备注】1. …；2. …；3. …
```

## 四条硬要求

### ① 写时间码，模型会照着切

实测：写 `[00:00-00:02.5]` 分界，切点落在 **2.458 秒**，误差 1.7%。
不写时间码的同一类三镜段落，出来是 0.6/1.2/3.4 秒。

⚠️ 不保证严格执行 —— 实测有过「多切一刀」和「该切没切」。
**时间码是强引导不是硬约束**，验收时仍要用场景检测核对：

```bash
ffmpeg -v info -i 片.mp4 -vf "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep -oE "pts_time:[0-9.]+"
```

### ② 关系感要写成「距离 + 朝向镜头的物理动作」

这是第一人称片型的命门。抽象关系描述一律失败：

| ✗ 抽象关系 | 实际出的 | ✅ 物理动作 | 实际出的 |
|---|---|---|---|
| 她的头靠在镜头的肩上 | 她独自躺在草地 | 站在镜头前**一臂距离** | 正确的 POV 框感 |
| 两个背影并肩走远 | 她的侧脸特写 | **一步一步凑近镜头，越来越近直到脸占满画面** | 完整的逼近过程 |
| — | — | 慢慢**贴向镜头**像要亲上来 | 噘嘴贴近，完全做到 |

**模型理解「镜头在哪、人朝镜头做什么」，不理解「你和她的关系」。**

### ③ 角色描述每段原样重复

纯 T2V 没有任何东西约束跨段人物一致性。踩过：段 0 写了完整外貌、段 1 起简写成「the girl」，
结果段 0 是黑色短发蓝外套，段 1 变成长金发白裙。

把角色描述做成常量，每段拼进去：

```python
GIRL = "二十二岁东亚女生，齐下巴黑色短发，牛仔蓝外套内搭白T，未化妆"
```

⚠️ **剪影镜头也要带** —— 看不清脸，但衣着轮廓差别一眼就出戏。

有参考图通道的 profile（H3 Ref2VA 最多 9 张）可以改用参考图锁形象，更硬。

### ④ 【导演备注】写硬规则，模型会遵守

实测有效的几条：

```
1. 全程单机位手持，保留轻微自然手抖，禁止稳定器般的平滑运镜
2. 镜头间为单帧硬切，相邻镜头景别必须不同
3. 切点卡在动作进行中段，禁止动作做完再切
4. 每个镜头人物手部必须有动作，禁止呆立定格
5. 场景、光线、服装全程不变，只变机位与姿势
6. 首尾呼应
```

写成编号的祈使句，不要写成描述句。

## 按片型调节奏

节奏在这套写法里**不是剪辑参数，是「每段塞几个镜头」**：

| 片型 | 每段镜数 | 写法要点 |
|---|---|---|
| 预告片 / 快节奏 | 3 | 每镜 ~1.7 秒，动作卡在中段切 |
| 日常 vlog | 2 | 每镜 ~2.5 秒，留出表情反应时间 |
| **治愈 / 情绪片** | **1–2** | **每个动作做完要「停住」「保持不动」，不要把时间填满** |
| 凝滞 / 长镜 | 1 | 整段一个连续动作弧线 |

治愈系那条最反直觉：**留白比动作重要**。在镜头描述里直接写「停住」「保持这个眼神」「谁都没动」，
否则模型会用小动作把 5 秒填满，情绪就散了。

## 旁白（画外音）

有对白能力的 profile 上，旁白直接写进提示词。**但必须显式声明画外音**，
否则模型的默认理解是「有对白 = 画面里有人在说」，会安排一个人对着镜头念：

```
A male Mandarin Chinese voiceover says: “…”
The narrator is never visible and no one on screen is speaking or moving their lips.
```

⚠️ 画面里若有人物出镜，**额外在该镜写 `mouth firmly closed`** 双保险。

旁白长度按语速配：中文约 **每秒 2.5–3 字**（比正常语速慢，留停顿）。
5.17 秒的段落一句 12–18 字为宜，写长了会被截断或语速失控。
