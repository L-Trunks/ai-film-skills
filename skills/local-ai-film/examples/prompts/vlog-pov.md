# 男友视角 POV vlog

第一人称关系感的范例。关键在**距离 + 朝向镜头的物理动作**：
「站在镜头前一臂距离」「一步一步凑近镜头，越来越近直到脸占满画面」
「慢慢贴向镜头像要亲上来」—— 这些能做到，而「头靠在镜头的肩上」做不到。

> 实测配置：2 段 / 4 镜 / 10.3 秒 / 画幅 (416, 736)

---

## 段 0（2 镜）

```
【风格】POV男友视角实拍感（first-person boyfriend POV），竖屏手持轻微晃动，夏日傍晚自然光，清新甜妹日常Vlog质感，色调明亮柔和带一点暖橘，35mm胶片颗粒
【场景】夏日便利店门口台阶，傍晚余晖洒下暖光，背景霓虹虚化干净
【角色】主角（二十二岁东亚女生，齐下巴黑色短发，牛仔蓝外套内搭白T，未化妆）
【道具】一支咬了一口的雪糕 + 一瓶冒气泡的汽水
【时长】5.2秒
[00:00-00:02.5] 镜头1
画面：POV视角，主角站在镜头前一臂距离，举起雪糕舔了一小口，眼睛弯弯对镜头甜甜一笑，身体轻轻左右晃了晃
台词：（元气可爱地）这个雪糕，是甜的～
音效：环境细碎人声，轻快甜系BGM起
[00:02.5-00:05.2] 镜头2
画面：硬切。她把雪糕换到另一只手，举起汽水啵地拧开喝一小口，气泡冒起，眯眼笑着把瓶子朝镜头晃了晃
台词：这瓶汽水，也是甜的～
音效：开盖气泡滋声，BGM节奏轻点
【导演备注】1. 全程POV男友视角单机位手持，保留轻微自然手抖，禁止稳定器般的平滑运镜；2. 镜头间为单帧硬切，相邻镜头景别必须不同；3. 切点卡在动作进行中段，禁止动作做完再切；4. 每个镜头人物手部必须有动作，禁止呆立定格；5. 场景、光线、服装全程不变，只变机位与姿势；6. 画面里只有主角一个人，镜头就是男友的眼睛。
```
